## Featured build: Recruiter Phone Screen Copilot

The RPS Copilot demonstrates how AI-assisted recruiting can go beyond generic prompts.

**Role criteria + de-identified resume → tailored questions → evidence guidance → recruiter notes → structured RPS**

It is designed to help recruiters spend less time researching roles, building questions, organizing notes, and documenting initial evaluations — while keeping the recruiter responsible for the final assessment.

[**Try the RPS Copilot live →**](https://matthewrojas090-hash.github.io/ai-recruiting-operations-command-center/rps-copilot.html)

In an earlier professional workflow, I measured approximately **20 hours saved per recruiter per month** and a **10-day reduction in time-to-fill**. Those results provide context for the problems I am exploring here and are not guaranteed outcomes of these portfolio prototypes.

## How I think about AI

The goal is not to remove people from people decisions.

I build workflows that use AI to organize information, accelerate repetitive work, surface gaps, and improve consistency — while preserving **human judgment, privacy, evidence verification, and accountability**.
